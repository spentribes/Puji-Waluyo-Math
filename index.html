Simpan & Terbitkan

Unduh & Ekspor

Halaman ini tidak memiliki server, jadi perubahan disimpan lewat unduhan file — bukan otomatis. Ikuti langkah di bawah agar perubahanmu tidak hilang.

1. Unduh Website Terbaru

Membuat ulang file mathspace.html lengkap dengan semua tautan dan konten yang sudah kamu isi. Unggah file ini ke hosting sekolah untuk menggantikan versi lama.

2. Ekspor Konfigurasi (cadangan)

Simpan file JSON kecil berisi semua isian kamu. Gunakan ini untuk melanjutkan pengeditan nanti tanpa harus mengetik ulang — impor lewat tombol "Impor Konfigurasi" di pojok kanan atas.

Alur kerja yang disarankan: (1) Muat mathspace.html yang sedang aktif jika kamu sudah pernah mengeditnya sebelumnya, (2) isi/perbarui tautan di panel kiri, (3) unduh website baru untuk dipublikasikan, dan (4) ekspor konfigurasi JSON sebagai cadangan sebelum menutup halaman ini.
